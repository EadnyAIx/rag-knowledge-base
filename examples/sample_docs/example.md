# RAG 知识库问答系统示例文档

## 项目简介

这是一个基于检索增强生成（Retrieval-Augmented Generation, RAG）技术的知识库问答系统。系统通过将文档向量化存储，在用户提问时先检索相关内容，再结合大语言模型生成准确回答。

## 核心技术栈

- **LangChain**: 大语言模型应用开发框架，提供文档加载、分块、链编排等能力
- **ChromaDB**: 轻量级向量数据库，支持持久化存储和相似度检索
- **OpenAI API**: 提供文本嵌入模型和对话生成模型
- **Streamlit**: 快速构建交互式 Web 界面

## 系统架构

```
用户提问 → 查询向量化 → 向量检索 → 上下文组装 → LLM 生成 → 返回回答
                ↑
文档加载 → 文本分块 → 批量向量化 → 持久化存储
```

## 检索策略

1. **相似度检索 (Similarity)**: 基于向量余弦相似度，返回最相关的 Top-K 文档
2. **最大边际相关性 (MMR)**: 在相关性和多样性之间取得平衡，避免返回内容高度重复的文档
3. **混合检索 (Ensemble)**: 结合向量相似度检索和 BM25 关键词检索，兼顾语义匹配和精确匹配

## 使用场景

- 企业内部知识库问答
- 学术文献检索与总结
- 产品文档智能助手
- 法律合同条款查询
- 医疗健康知识咨询
